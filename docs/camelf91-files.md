# CAMEL24 LOAD and SAVE through native ports

The Kit's CAMEL24 tab uses the native QEMU file and console device described in
[CP/M drive backends](cpm-hostfs.md). The Forth definitions execute I/O
instructions; QEMU reads and writes files on the shared CP/M image/directory drives.

```forth
3 S" F24ALL.F24" LOAD
: SQUARE DUP * ;
3 S" WORK.F24" SAVE
```

Both words have stack effect `( drive c-addr u -- )`. Drives are numeric:
`0` = A:, `1` = B:, ... `15` = P:. Values outside 0..15 are rejected.
The optional `A:` through `P:` aliases push those same numeric values.
`S" NAME.F24"` pushes filename address and length, both at the prompt and
inside colon definitions. Names use CP/M 8.3 matching.

`LOAD` evaluates one line at a time. Lines may contain at most 124 bytes;
multiline definitions are supported. An unknown word aborts loading and returns
to the interpreter. Nested LOAD is rejected.

`SAVE` writes the entered session source, including source read by LOAD. Output,
startup helper definitions and directly entered LOAD/SAVE commands are excluded.
The saved source can be replayed; it is not a binary dictionary snapshot.
Restart clears the recorded source and the Forth dictionary. Existing source
files are replaced; Unix read-only permissions are respected.

Files default to `cpm-files/D/name.f24` (D:, user 0). Select another user area:

```forth
1 FS-USER !
3 S" WORK.F24" SAVE       ( cpm-files/D/1/work.f24 )
0 FS-USER !
```

Use `--fs-root /path/to/files` for another Unix tree. The **CP/M 2.2** tab
uses the same mounts. A drive can instead be an image file, for example
`cpm-files/D.img` (remove the conflicting `D/` mount first). LOAD/SAVE uses
the image directly, including its user areas, capacity and read-only attributes.

`D:F24ALL.F24` contains the dictionary tests generated by
`examples/camelf91/word_tests.py`. Its final result is:

```text
TESTS 198 FAILURES 0
```

The Qt integration test also verifies source SAVE/LOAD, colon-definition calls,
missing-file recovery and visibility of a Forth-saved file in the native CP/M tab.
